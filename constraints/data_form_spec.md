# 公式/符号/数据统一口径规范

> 本文件定义润色过程中涉及公式、符号、数据表述的统一口径，作为 rule_base.md 中规则 14/16/20/22/23 的操作细则；不改变任何数值本身。

## 一、公式统一口径
1. 公式一律按原文原样保留，不得改写符号、下标、上标、编号
2. 重要公式独立成行并保留原编号；原文无编号时不新增编号
3. 公式中符号首次出现处须定义：符号（含义）（单位），如 c 为真空中的光速（m/s）
4. 同一符号在一篇文章中只代表一个物理量；冲突时仅提示作者，不改写
5. 行内公式与显示公式的符号样式全文一致（如斜体/正体使用习惯）

## 二、符号统一口径
1. 单位符号使用国际单位制标准写法：Pa、kPa、m/s、kg/m³、×10⁵（上标统一）
2. 数值与单位间保留半角空格：0.92 m/s，5×10⁵ Pa
3. 百分号紧跟数值：12.4%，不写「百分之十二点四」
4. 统计符号规范：样本量 n 斜体、相关系数 R、显著性 p（小写斜体）
5. 中英文混排符号不混用字体：变量统一为斜体，单位统一为正体

## 三、数据表述统一口径
1. 同一物理量全文小数位一致（如统一保留两位小数）
2. 有效数字与精度表述一致：误差 ±0.5°、波动 ±2% 写法统一
3. 单位换算后全文统一使用同一单位，禁止 Pa/kPa 混用
4. 误差/偏差必须指明对比基准（试验值 vs 计算值、本文 vs 对比文献）
5. 区间表述统一使用「~」或「–」中的一种，全文不混用
6. 数量级统一使用科学计数法或十进制，全文一致

## 四、数据一致性校验清单（Step4 复检使用）
- [ ] 摘要、正文、图表、结论中的同一数据数值一致
- [ ] 百分比/百分点使用准确，无「提高了 5%」类歧义
- [ ] 工况、条件、样本量等限定信息在数据首次出现处前置
- [ ] 发现冲突数据：输出提示由作者确认，不擅自修改
