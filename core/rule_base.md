# 通用学术论文24条写作修改规则库

## 说明
本文件独立解耦，skill_main.md 通过引用加载；新增/修改规则仅更新本文件，无需改动主工作流。
分类：结构组织、逻辑因果、术语符号、数据验证、公式结果
- 1~6   结构与组织规则
- 7~11  逻辑与因果规则
- 12~15 术语、符号与表述规则
- 16~22 数据、统计与验证规则
- 23~24 公式与结果规范

规则编号为稳定标识，迭代时新增规则顺延编号，废弃规则保留编号并标注「已废弃」，禁止重排历史编号。

---

## 一、结构与组织规则（1~6）

### 规则 1：删除章节预告句式
禁止使用「本章将介绍……」「下面讨论……」「接下来阐述……」等预告句式，改为直接陈述内容本身。

- 反例：本章将介绍参数反演方法的实现过程，首先讲测点布置，其次讲数据处理。
- 正例：本节构建参数反演方案，包含测点布设与数据处理两大模块。

### 规则 2：删除节号自指与章节位置提示
正文中禁止出现「如本节 3.2 所述」「上文提到」「见后面的分析」等自指表述；确需引用时改用内容化表述。

- 反例：如 3.2 节所述，该工况下总压恢复系数较高。
- 正例：该工况下总压恢复系数为 0.92，与测点布置分析结论一致。

### 规则 3：规范章首导语
章首导语须直接切入主题，给出本章研究内容与范围，禁止空泛铺垫与无信息量的开场。

- 反例：风洞试验是空气动力学研究的重要手段，本章内容较多，主要进行试验描述。
- 正例：本章开展某型翼型低速风洞试验，测量不同攻角下的表面压力分布，用于标定 CFD 计算模型。

### 规则 4：标题名词化
章节标题与图表标题使用名词性短语，禁止使用完整句子、动词开头或带标点结尾的表述。

- 反例：试验中我们如何布置测点
- 正例：试验测点布置方案

### 规则 5：段落单一主题
一段只表达一个中心思想；同一段落内不得混入多个并列主题，确需并列时拆分为独立段落。

- 反例：（一段内）先讲测点布置，再讲数据处理流程，最后又讨论误差来源。
- 正例：段落一讲测点布置，段落二讲数据处理流程，段落三单独分析误差来源。

### 规则 6：结构顺序遵循研究逻辑
章节内容顺序遵循「背景→方法→试验/仿真→结果→讨论→结论」主线；同一层级内容并列项顺序前后一致，不随意跳转。

- 反例：先给结论性数据，再补试验方法，最后才交代研究背景。
- 正例：按研究背景、方法设计、试验实施、结果分析顺序组织内容。

## 二、逻辑与因果规则（7~11）

### 规则 7：先因后果语序
因果关系的表述一律「先因后果」；「因为……所以……」「由于……因此……」的语序不得颠倒。

- 反例：误差明显偏大，由于测点布置间距过小。
- 正例：由于测点布置间距过小，导致测量误差明显偏大。

### 规则 8：消除伪因果
「由于/因为/因此/所以」必须连接真实的因果链条，禁止把时间先后、并列关系误写成因果关系。

- 反例：由于采用了新算法，因此试验安排在下午进行。
- 正例：由于采用了新算法，计算耗时缩短了 30%，因此完成了全工况遍历。

### 规则 9：统一叙述顺序
对多个同类对象（如多组工况、多个部件、多个方案）的描述，须按同一顺序展开，禁止各段顺序不一致。

- 反例：方案 A 段按「设计-验证-结论」写，方案 B 段按「结论-设计-验证」写。
- 正例：所有方案均按「方案设计-试验验证-结果结论」统一顺序描述。

### 规则 10：补充段落过渡
句间、段间须有明确逻辑衔接（承接、转折、因果、递进），禁止生硬跳转。

- 反例：试验完成。接下来算误差。误差不大。该方法可用。
- 正例：试验完成后，对测量数据与 CFD 结果进行对比分析，二者偏差较小，表明该方法在试验范围内适用。

### 规则 11：观点-论证-推导完整逻辑链
每个结论性观点须有论证支撑或推导过程，禁止「观点直接跳结论」或「论证缺失」。

- 反例：该算法优于对比算法。因此本文方法更好。
- 正例：全工况下本文算法 RMSE 均值为 0.21，低于对比算法的 0.35，表明本文算法预测精度更优。

## 三、术语、符号与表述规则（12~15）

### 规则 12：全文术语统一
同一概念全文只能使用同一名称，禁止同义混用（如「总压恢复系数/总压恢复率」「测点/测量点」「工况/工作状态」）。

- 反例：该工况下总压恢复系数为 0.92，总压恢复率保持稳定。
- 正例：该工况下总压恢复系数为 0.92，且在不同攻角下保持稳定。

### 规则 13：缩写首次定义
缩写/英文简称首次出现时须给出中文全称（必要时给出英文全称），后续方可单独使用。

- 反例：CFD 结果显示压力分布均匀。
- 正例：计算流体力学（CFD）结果显示压力分布均匀；后续分析中 CFD 结果与试验数据吻合良好。

### 规则 14：符号体系隔离
不同来源、不同体系的符号禁止混用；同一符号全文只代表同一物理量；符号冲突时须明确区分或改用其他符号。

- 反例：文中 F 既表示力又表示频率，且未作说明。
- 正例：力 F、频率 f 分用不同符号，并在首次出现处定义。

### 规则 15：删除主观模糊与口语化表述
删除「精度较高、效果很好、误差偏低、众所周知、非常、明显（无数据支撑时）」等主观模糊词；有数据支撑时替换为量化描述，无数据支撑时删除。

- 反例：该方法的精度还是不错的，效果很好。
- 正例：该方法预测误差的 RMSE 为 0.21，满足工程精度要求。

## 四、数据、统计与验证规则（16~22）

### 规则 16：数据必须带对比对象与偏差基准
误差、偏差、提升量等表述必须指明「相对谁、在何种基准下」，禁止裸用数值。

- 反例：误差为 0.05。
- 正例：试验值与 CFD 计算值相比，总压偏差为 0.05（相对偏差 1.2%）。

### 规则 17：公共工况条件前置
数据、结论前先交代适用的工况、条件、范围，禁止先给数据后补条件。

- 反例：阻力系数为 0.35。本试验雷诺数为 5×10⁵。
- 正例：在雷诺数 5×10⁵ 的试验条件下，阻力系数为 0.35。

### 规则 18：定性/定量表述区分
能用数值表达的必须量化；「明显、显著、大幅」等定性词须有统计检验或数值依据支撑，否则删除或替换。

- 反例：加入该结构后性能明显提升。
- 正例：加入该结构后，升阻比由 12.4 提升至 14.1，提升幅度 13.7%。

### 规则 19：统计量描述标准化
统计量（RMSE、MAE、R²、相关系数、置信区间、显著性水平等）表述须规范：给出统计量名称、数值、单位（如适用）与样本范围。

- 反例：相关性系数 R 为 0.95，效果显著。
- 正例：试验与仿真结果的相关系数 R = 0.95（n = 120，p < 0.01），二者具有显著正相关。

### 规则 20：数据单位与精度统一
同一物理量的单位、小数位数、有效数字全文一致；换算关系明确的单位不得混用（如 Pa 与 kPa 须统一）。

- 反例：压力 101325 Pa，另一处写 101.3 kPa。
- 正例：压力全文统一为 kPa，写作 101.3 kPa。

### 规则 21：数值一致性检查
同一数据在摘要、正文、图表、结论中出现多次时数值必须一致；发现冲突时仅提示，不擅自修改。

- 反例：摘要写 RMSE = 0.21，正文结论写 RMSE = 0.35。
- 正例：摘要与正文结论 RMSE 均为 0.21；若发现不一致，输出提示由作者确认。

### 规则 22：百分比与绝对量区分
「提高了 5%」与「提高了 5 个百分点」含义不同，须按实际含义准确表述；比例数据的增减用百分点。

- 反例：识别率由 90% 提高到 95%，提高了 5%。
- 正例：识别率由 90% 提高到 95%，提高了 5 个百分点（相对提升 5.6%）。

## 五、公式与结果规范（23~24）

### 规则 23：带编号公式规范
重要公式独立成行、右对齐编号；公式中每个符号首次出现时给出定义与单位；不得拆分、篡改公式及下标。

- 反例：由能量守恒可得 E=mc²，其中 c 是光速（公式无编号，符号定义缺失）。
- 正例：由能量守恒可得
  E = mc²        （1）
  式中：E 为能量（J）；m 为质量（kg）；c 为真空中的光速（m/s）。

### 规则 24：结果与公式/机理描述一致
结果描述必须与公式推导、机理分析保持一致；重复出现的结果/机理描述合并，禁止同一结论多次复述。

- 反例：正文先详述某机理，下一段又用不同措辞复述同一机理，且数据与公式不一致。
- 正例：机理分析集中于一处展开，后续引用时仅作简要指代，数据与公式推导保持严格一致。
