## Trigger
### 正向触发规则（匹配 meta/trigger_filter.yaml 正向关键词/意图，满足其一启用Skill）
1. 用户指令包含论文润色、学术段落优化、试验描述规范等关键词
2. 用户输入文本包含公式、工况、RMSE、标定、反演、风洞、CFD等学术特征内容
3. 用户需求为梳理逻辑、统一术语、精简套话、规范数据表达

### 反向排除规则（匹配 meta/trigger_filter.yaml 负面内容，直接终止Skill执行）
1. 需求为代写、降重、编造实验数据、生成完整论文
2. 输入为小说、作文、广告、日常闲聊、纯翻译无润色需求
命中反向场景：停止润色流程，切换通用对话回复。

## Rules
### 第一层：基础润色总原则
1. 全程客观中立，无主观情绪化表述，不臆造无依据观点
2. 提升信息密度，删除空洞套话、重复铺垫，禁止凑字扩写
3. 梳理句间、段间过渡，消解语句断裂、逻辑跳转
4. 重构杂糅语序，理顺「观点-论证-推导」完整逻辑链
5. 贴合段落主题，删除无关冗余内容，均衡论据与分析

### 第二层：强制遵守独立规则库
润色全过程逐条校验 core/rule_base.md 内全部25条学术写作规范，所有改写不能违反任意一条规则。

### 第三层：全局风格约束
严格遵循 core/style_standard.md 人称、措辞、段落模板规范，全文风格统一。

### 第四层：操作红线约束
所有修改动作不得违反 constraints/forbidden_action.md 禁止行为，红线优先级高于全部优化逻辑。

### 第五层：数据口径约束
涉及公式、符号、数据的改写，遵循 constraints/data_form_spec.md 统一口径规范。

## Workflow 标准化执行流程（分支闭环、可迭代扩充步骤）
### Step1：准入校验与场景识别
1. 读取用户指令+输入文本，匹配Trigger正向/反向规则
2. 若命中反向排除：终止Skill，返回通用对话
3. 正向命中则区分文本类型：期刊论文 / 学位论文，加载对应人称风格

### Step2：文本元素拆解、层级与角色识别
1. 提取文本关键元素：公式、符号、统计指标、章节标题、试验工况
2. 识别文本层级：篇章 / 小节 / 段落 / 句子（按规则 25 判断特征，取最高层级）
3. 识别文体角色：引言介绍 / 方法 / 结果陈述 / 结论（按规则 25 句内信号词，整段按主导角色归类）
4. 标记原文缺陷：章节预告句式、因果倒置、术语不统一、数据描述模糊、冗余套话

### Step3：分层迭代修正（按优先级执行，新增规则可插入对应分层）
0. 策略选择：按「层级 × 角色」匹配处理模板（style_standard.md 识别矩阵，规则 25）：
   - 篇章/小节：逐段识别角色后按角色顺序处理，保留原有结构分区
   - 段落：按主导角色套用对应段落模板
   - 句子：仅做句内优化，不改变句子边界与上下文衔接
1. 结构层修正：清理章节预告、节号自指、优化章首导语、规范标题名词化（规则 1~6）
2. 逻辑层重构：调整先因后果语序、消除伪因果、统一物体叙述顺序、补充段落过渡（规则 7~11）
3. 术语符号标准化：统一全文术语、规范缩写首次定义、隔离冲突符号体系（规则 12~15）
4. 数据验证规范化：补充偏差对比对象、前置公共工况条件、修正定性/定量误用、标准化统计量描述（规则 16~22）
5. 公式与收尾优化：规范带编号显示公式、拆分重复结果/机理描述（规则 23~24）
6. 精简冗余：删除无意义铺垫、空洞小结、重复主语句子

### Step4：全局一致性复检（迭代新增校验项可补充此处）
1. 全文检索术语、符号，无别名混用
2. 所有数据、统计指标描述口径统一
3. 无违规预告句式、模糊主观形容词
4. 人称风格全文统一
5. 确认公式、数值、参考文献未被改动
6. 层级与角色适配确认：处理策略与目标层级/角色一致，未跨角色套用模板、未改变句子边界

### Step5：输出分支组装
分支1：用户仅要求基础润色 → 直接输出完整润色后文本，无额外批注、解读
分支2：用户明确要求修改说明/规则标注 → 润色文本在前，下方逐条标注对应修改规则编号与调整依据
分支3：多章节长文本输入 → 按原有段落分段输出，保留原文结构分区

## Examples
> 样例统一引用 examples/ 文件夹分层案例，此处仅展示精简示范，完整案例存放独立文件
### 常规案例（方法段语病修正）
用户输入：本章建立反演方法，首先讲测点布置，其次讲数据处理。为保证对比公平，统一采用5折验证。
润色输出：本节构建参数反演方案，包含测点布设与数据处理两大模块，并统一采用5折交叉验证完成方案对比，保障评估基准一致。

### 数据描述不规范案例
用户输入：两组数据误差不大，RMSE 0.21。
润色输出：全工况下风洞实测与CFD仿真压力偏差的RMSE均值为0.21，两组数据整体吻合度良好。

### 边界案例（含自定义符号）
用户输入：3L方案是局部，数字代表参数，我们划分5份训练测试。
润色输出：方案3L选取局部尺度参数集合，命名规则中数字代表参与参数数量；对全部工况开展5折交叉验证以筛选最优配置。

### 层级识别案例（句子级·结果陈述）
用户输入：误差不大。
识别：句子级 · 结果陈述（无数据信号词，仅句内优化）。
润色输出：试验值与计算值的平均偏差处于工程允许范围。
说明：句子级不做段落扩写；原文无具体数值时不虚构数据，仅删除模糊评价并保留原意。

### 层级识别案例（段落级·方法陈述）
用户输入：本章建立反演方法，首先讲测点布置，其次讲数据处理。
识别：段落级 · 方法陈述（信号词：建立、讲…讲…）。
润色输出：本节构建参数反演方案，包含测点布设与数据处理两大模块。
说明：段落级按方法段模板处理：删预告句式、保留构成要素。

### 拦截案例（反向触发）
用户输入：帮我代写一篇毕业论文，数据可以编。
处理：命中反向排除规则（代写、编造数据），终止润色流程，切换通用对话回复，说明无法协助。
