# 学术论文风格基准规范

## 一、人称统一规则
1. 期刊小论文：全文统一使用「我们」
2. 硕博学位论文：全文统一使用「本文」
3. 禁止同一文本混用两种人称
4. 单数/复数主体不混用：同一段落内主语指代一致

## 二、措辞约束
1. 删除模糊形容词：精度较高、效果很好、误差偏低、性能优良
2. 全部量化描述替换为数值范围：误差±0.5°、总压波动±2%、升阻比 12.4→14.1
3. 句式以陈述句为主，多用「由……构成/控制/实现」客观句式
4. 禁止感叹句、反问句、设问句等非学术语气
5. 禁止广告化表述：行业领先、国际先进、填补空白（无客观依据时）

## 三、段落结构模板
1. 引言漏斗式：应用场景→现有方法对比→研究缺口→本文研究目标
2. 方法段：现有方案缺陷→本文方案设计→评估方式
3. 结果段：量化数据规律→分层对比→可推广边界收尾
4. 结论段：总结核心成果→局限→未来拓展方向

## 四、英文辅助规范（面向中英混排文本）
1. 避免简单短句堆砌，采用复合学术句式
2. 避免口语化连接词：so、but，替换为 therefore、however
3. 中英文术语混排时，首次出现的英文术语后括注中文译名或反之，全文统一
4. 单位符号与数值间留半角空格：5×10⁵ Pa、0.92 m/s

## 五、时态与语态建议（英文段落）
1. 方法描述用一般过去时或一般现在时，全文统一
2. 结果与结论用一般现在时
3. 优先被动语态描述试验过程，主动语态描述分析判断
