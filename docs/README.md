# docs/ 目录说明

本目录存放项目文档与静态资源。

## 捐赠收款码（可选）

如需在 README 首页展示捐赠收款码：

1. 将收款码图片（PNG/JPG，建议尺寸 300×300 以内）保存为本目录下的 `donate-qr.png`
2. 打开仓库根目录 `readme.md`，找到「💖 捐赠支持」小节
3. 取消下面这行注释：

```markdown
<!-- ![捐赠收款码](docs/donate-qr.png) -->
```

改为：

```markdown
![捐赠收款码](docs/donate-qr.png)
```

4. 提交并推送，README 首页即可展示收款码
