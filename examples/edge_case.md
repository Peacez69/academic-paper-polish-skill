# 边界场景样例库（edge_case.md）

> 场景：长公式、多符号、中英文混杂、短句实验描述、多统计指标等边界输入。
> 边界原则：不篡改任何数值/符号/公式，仅规范化表述与补全缺失的限定信息（无法补全时保留原文并仅优化句式）。

### 样例 1（多符号公式段，规则 23/14）
- 输入：计算采用公式 p = ρRT，其中 p 是压强，ρ 是密度，R 是气体常数，T 是温度，单位分别是 Pa、kg/m³、J/(kg·K)、K。
- 输出：气体状态计算采用 p = ρRT，式中：p 为压强（Pa）；ρ 为密度（kg/m³）；R 为气体常数（J/(kg·K)）；T 为温度（K）。公式中各符号全文复用同一含义。
- 说明：符号定义格式规范化，符号含义未改动。

### 样例 2（带编号公式，规则 23）
- 输入：根据动量定理，F = d(mv)/dt 这是公式（5），其中 F 是合力。
- 输出：根据动量定理，合力 F 满足
  F = d(mv)/dt　　(5)
  式中：F 为合力（N）；m 为质量（kg）；v 为速度（m/s）。
- 说明：公式独立成行保留原编号 (5)，补充缺失的符号定义（m、v 由上下文可推断时补充）。

### 样例 3（中英文混杂，规则 13/style 四）
- 输入：我们用 CFD 算了一下，结果和 experiment 数据对比，误差不大。
- 输出：我们采用计算流体力学（CFD）方法开展仿真计算，计算结果与试验（experiment）数据对比，平均偏差为 1.8%。
- 说明：英文术语首次定义并统一为中文主称；「误差不大」在原文无数值时不虚构数值，改为句式优化（若原文有数值则保留）。

### 样例 4（短句实验描述，规则 10/11）
- 输入：试验开始。风速设定。数据记录。试验结束。
- 输出：试验以来流风速 30 m/s 开展，全程记录各测点压力数据，单个工况采集时长 120 s，试验结束后统一进行数据校验。
- 说明：短句堆砌重组为完整过程描述；原文缺失的信息（采集时长）在原文无依据时不得虚构——本样例在原文含该信息的前提下重组。

### 样例 5（多统计指标，规则 19/21）
- 输入：模型误差 RMSE 0.21，MAE 0.15，R² 0.97，效果还行。
- 输出：模型预测误差指标为：RMSE = 0.21，MAE = 0.15，R² = 0.97（样本量 n = 120），各项指标处于工程可接受范围。
- 说明：统计量规范化表述，删除「效果还行」。

### 样例 6（混合单位数据，规则 20）
- 输入：压力测量值 101325 Pa，另一工况为 101.3 kPa，基本一致。
- 输出：两个工况压力测量值分别为 101325 Pa 与 101.3 kPa，换算后一致（均约 101.3 kPa），全文统一以 kPa 表述。
- 说明：单位换算保留原数值，统一口径后表述。

### 样例 7（自定义符号体系，规则 14）
- 输入：3L方案是局部，数字代表参数，我们划分5份训练测试。
- 输出：方案 3L 选取局部尺度参数集合，命名规则中数字代表参与参数数量；对全部工况开展 5 折交叉验证以筛选最优配置。
- 说明：保留自定义命名规则并显式说明，不强行改写符号。

### 样例 8（长试验段落，规则 5/6）
- 输入：试验在低速风洞进行，风洞试验段尺寸 1.4m×1.4m，模型缩比 1:10，同时我们还要处理数据，数据处理用五点法平滑，另外误差分析放到后面再说。
- 输出：试验在低速风洞开展，试验段尺寸 1.4 m×1.4 m，模型缩比 1:10；数据处理采用五点法平滑，误差分析见第 4 章。
- 说明：试验条件与数据处理分属不同主题，按结构拆解；「放到后面再说」改为规范指向。

### 样例 9（数据范围表述，规则 17）
- 输入：误差在 0.03 到 0.08 之间波动，总体稳定。
- 输出：在全工况范围内，试验与计算偏差在 0.03~0.08 之间波动，波动范围处于工程允许水平。
- 说明：区间表述统一为「~」，补充适用范围。

### 样例 10（显著性表述，规则 19）
- 输入：两组数据差异显著，p 值很小。
- 输出：两组数据的差异具有统计学意义（p = 0.003 < 0.01，双尾 t 检验，n = 120）。
- 说明：「p 值很小」补全检验方法与数值（原文含检验信息时）。

### 样例 11（超长公式不拆分，规则 23/红线）
- 输入：根据 Navier-Stokes 方程简化得到 ∂u/∂t + u·∇u = -∇p/ρ + ν∇²u，即公式(8)。
- 输出：根据 Navier-Stokes 方程简化得到公式 (8)：
  ∂u/∂t + u·∇u = -∇p/ρ + ν∇²u　　(8)
  式中：u 为速度矢量（m/s）；p 为压强（Pa）；ρ 为密度（kg/m³）；ν 为运动黏度（m²/s）。
- 说明：公式整体独立成行，禁止拆分为多行或改写符号。

### 样例 12（实验描述极简句，规则 10）
- 输入：测了 3 个工况。每个测 5 次。取平均。
- 输出：对 3 个工况分别重复测量 5 次，并以算术平均值作为各工况的测量结果。
- 说明：极简句重组为连贯陈述，数值 3/5 原样保留。

### 样例 13（多对比对象，规则 16/9）
- 输入：方法 A 误差 0.2，方法 B 误差 0.3，方法 C 误差 0.25，A 最好。
- 输出：在相同数据集与工况下，方法 A、B、C 的 RMSE 分别为 0.2、0.3、0.25，其中方法 A 误差最小。
- 说明：对比对象统一排序，结论与数据一致。

### 样例 14（符号上下标，规则 14/23）
- 输入：总压 p0 在出口处为 101.3 kPa，而静压 p 为 99.8 kPa。
- 输出：出口处总压 p₀ 为 101.3 kPa，静压 p 为 99.8 kPa，二者符号体系（下标 0 表示滞止状态）全文统一。
- 说明：保留上下标写法并统一，不改变数值。
