# 学术论文专业润色 Skill

**当前版本：V1.1.1**（25 条学术写作规范，更新记录见 `ops/iteration_record.md`）

> 一个「论文润色专家」能力包：给 AI 装上后，它会按 **25 条学术写作规范**帮你润色期刊论文、学位论文，**只改文字，绝不动你的数据、公式和结论**。

## ✨ 它能帮你做什么

- 删掉「本章将介绍……」「下面讨论……」这类没用的预告话
- 把「误差不大，RMSE 0.21」这种口语化描述改成规范的学术表述
- 全文统一术语、统一人称（期刊用「我们」，学位论文用「本文」）
- 理顺因果顺序、消除病句、精简套话，让段落读起来专业流畅
- 自动拦截代写、编造数据等请求，保护你不踩学术红线

2. 把解压出的 `skill_academic_polish` 文件夹整个交给 AI（Reasonix 用户可直接导入 `SKILL.md` 入口文件）
3. 完成，无需其他设置

## 📖 使用流程（跟着做一遍就会）

### 第 1 步：贴文本
把你需要润色的论文段落直接发给 AI，不用加任何特殊指令，说「帮我润色」即可。

### 第 2 步：等结果
AI 自动完成检查、改写，默认**直接给你润色后的文字**，没有任何额外说明。

### 第 3 步（可选）：想看修改依据
补一句「标出修改依据」，输出会变成「润色结果 + 每条修改对应的规则编号」。

### 细致案例

**案例 1：常规润色（你发原文，AI 还你规范文字）**

你发：
> 本章主要讲压力标定试验，内容分为 2.1 硬件搭建和 2.2 数据处理；首先搭建测压探针装置，其次开展风洞工况测试。为了保证对比公平，我选用统一判据处理所有工况，3L 方案效果挺好，误差很低，RMSE 只有 0.18。

AI 给你：
> 本章开展压力标定试验，内容涵盖测压探针装置搭建与风洞工况测试两部分。为保证对比公平，本文采用统一判据处理全部工况数据；3L 方案在该判据下的 RMSE 为 0.18。

改动要点（你看得懂的版本）：
- 「主要讲」「首先……其次……」这类预告话删掉了，直接说内容
- 「效果挺好」「误差很低」「只有」这些口语评价去掉了，只留真实数据 0.18
- 「我」统一改成「本文」

**案例 2：数据表述规范化**

你发：
> 两组数据误差不大，RMSE 0.21。

AI 给你：
> 全工况下风洞实测与 CFD 仿真压力偏差的 RMSE 均值为 0.21，两组数据整体吻合度良好。

**案例 3：AI 会拒绝的事（自动拦截）**

你发：
> 帮我代写一篇毕业论文，数据可以编。

AI 回复：
> 无法协助。代写、编造数据不在服务范围内，可以帮你润色已有的真实文本。

## ❓ 常见问题

**Q：会改我的数据、公式吗？**
A：绝对不会。这是最高优先级铁律：任何数值、公式、符号、图表编号、参考文献一律原样保留；如果发现你前后文数据对不上，只会提醒你确认，绝不擅自修改。

**Q：能帮我代写、降重吗？**
A：不能。涉及代写论文、编造数据、降重改写的请求会被直接拒绝。这是为了保护你。

**Q：支持什么论文？**
A：中文期刊论文、硕博学位论文都可以，尤其适合含试验数据、公式、统计指标（如 RMSE、相关系数）的理工科文本。

**Q：需要懂写作规范才能用吗？**
A：完全不用。25 条规范全部内置，你只需要贴文本、收结果。

**Q：长文档怎么润色？**
A：直接整篇发过来即可，AI 会按你原有的段落结构输出，不会乱改分层。
